# Experiment Log
For every run record: run ID/date, commit, dataset hash, provider/model, prompt/schema versions, runtime and decoding settings, hardware, cases, parse success, schema compliance, field accuracy, unsupported-value rate, abstention metrics, runtime, inspected failures, interpretation, confounds, next experiment.

Rules: preserve raw outputs; never expose expected labels to the model; record all configuration; separate structural from semantic metrics; use deterministic checks for core metrics; distinguish hypotheses from observations.
