# DR-001 — Project differentiation
**Status:** provisional.

## Decision
Prototype a local-first regression workflow for structured extraction, with per-case evidence-linked diagnostics.

## Hypothesis
Evidence-linked diagnostics make regressions easier to investigate than aggregate scores alone.

## Validation
Use the same cases/assertions in SchemaStress and Promptfoo. Compare setup effort, failure traceability, categorization, and report usefulness.

## Kill/narrow criteria
If existing tools provide the same workflow with little friction, do not claim a differentiated framework; reposition as an engineering demonstration or narrow to a proven integration gap.
