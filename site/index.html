004 / METHODOLOGY

Show your work.

Reproducibility and limits are part of the result, not footnotes.

What was evaluated

A deterministic provider returns seeded outputs against 12 synthetic incident-extraction fixtures. SchemaStress computes parse success, schema validity, field accuracy and exact matches against expected labels.

Read the scorer ↗

What was not evaluated

No model inference, generalization, live inference latency, real-world accuracy or held-out model benchmark was measured in this dataset. These metrics should never be presented as Qwen scores.

View recorded historical run ↗

How to reproduce

The Python project is currently inside the repository's SchemaStress/ directory. Install its declared development dependencies, run pytest, and execute schemastress demo.
